🎵 Spotify Big Data Analytics with Apache Spark

A Big Data project that applies Apache Hadoop, Apache Spark SQL, and Spark MLlib to analyze over 232,000 Spotify tracks, identify music market opportunities, discover hit-song characteristics, predict song popularity, and automatically generate business dashboards.

📌 Project Overview

The project simulates a real-world music investment scenario where a record label uses Big Data technologies to support data-driven decision making.

📌 Key objectives:

- Process large-scale Spotify data using Hadoop HDFS and Apache Spark
- Perform advanced music market analysis with Spark SQL
- Identify high-potential genres, artists, and songs
- Build machine learning models to predict song popularity
- Generate automated dashboards for business insights

📌 About the dataset:
- Ultimate Spotify Tracks DB
- More than 232,000 Spotify songs
- Includes audio features, genres, artists, popularity scores, tempo, valence, energy, danceability, etc.

🛠 Technologies Used
- Storage:	Hadoop HDFS
- Processing: Apache Spark
- Query Engine:	Spark SQL
- Machine Learning	Spark MLlib
- Language	Python (PySpark)
- Visualization	Matplotlib
- IDE	PyCharm
